# AI Fitness Diet Assistant

## Project Overview
An AI fitness and diet assistant built with Coze for beginners and fat-loss users.  
This project helps users generate personalized workout plans and diet suggestions based on their goals, training conditions, and food preferences.

## Target Users
- Fitness beginners
- Fat-loss users
- Users who need simple and personalized fitness/diet guidance

## Core Problems
- Do not know how to train
- Do not know how to arrange diet plans
- Generic advice is hard to follow

## Core Features
- User basic information collection
- Goal identification (fat loss / muscle gain / body shaping)
- Workout plan generation
- Diet suggestion generation
- Food preference adaptation

## Workflow
1. Collect user basic information
2. Identify training goals and conditions
3. Generate workout plan
4. Generate diet suggestions
5. Return structured results

## Product Value
This project reduces the barrier for beginners to get personalized fitness and diet guidance through structured input and scenario-based output.

## Evaluation
Tested with 10 typical user scenarios:
- Plan generation success rate: 90%
- Goal matching rate: 80%
- Diet preference adaptation rate: 80%
- Actionability score: 4.2/5
